## 1. 项目概览

NeoForge 1.21.1 模组项目，基于 Project Moon 世界观的 Lobotomy Corporation / Limbus Company 同人模组。
采用多模块 Gradle + Kotlin 架构，KotlinForForge 开发业务代码，Java 仅用于 Mixin。

- **根项目**: `ImaginaryCraft`（伞模块，jarJar 聚合所有子模块）
- **主入口**: `architecture.imaginarycraft.ImaginaryCraft`（`@Mod("imaginarycraft")`）
- **全局配置**: `gradle.properties`（版本号），`build-conventions.gradle`（构建约定）
- **模块模板**: `templates/mods-base.toml`（neoforge.mods.toml 公共头部）

## 2. 模块依赖图

```
GoldenBoughsLib  ←───  ResonatorCombatFramework  ←───  EGOCurios
    ↑                         ↑                           ↑
    ├─────────────────────────┴───────────────────────────┤
    │                                                     │
    └──→  EGOEquipment  ──→  Abnormalities  ──→  ImaginaryCraft (聚合/jarJar)
```

各模块角色：

| 模块                           | 角色                             | 依赖                    |
|------------------------------|--------------------------------|-----------------------|
| **GoldenBoughsLib**          | 核心底层库：能力/属性/伤害/行为树/美德/HUD/渲染   | 无上游模块依赖               |
| **ResonatorCombatFramework** | 战斗框架：实体动画/装备渲染/碰撞              | GoldenBoughsLib       |
| **EGOCurios**                | 15槽位 Curios 饰品系统，~50 E.G.O. 饰品 | GoldenBoughsLib + RCF |
| **EGOEquipment**             | ~110 武器 + ~30 护甲套装             | GoldenBoughsLib + RCF |
| **Abnormalities**            | 异想体实体 + 考验实体                   | GoldenBoughsLib + RCF |
| **ImaginaryCraft**           | 伞模块，jarJar 聚合所有子模块             | 所有上述模块                |

## 3. 技术栈

- **Kotlin** — 所有业务代码（KotlinForForge）
- **Java** — 仅 Mixin 类（Kotlin 对 mixin 兼容性不好）
- **GeckoLib 4.8** — 3D 动画模型渲染（物品/护甲/实体/饰品）
- **MixinSquared** — Mixin 增强支持
- **Curios API** — 饰品槽位系统（15 槽位）
- **KMixin (KSP)** — Kotlin Mixin 生成
- **Jade** — 方块/实体信息显示
- **JEI** — 物品配方查看（编译时）

公共依赖版本在根 `gradle.properties` 中统一维护。

## 4. 构建系统约定

- `build-conventions.gradle` 提供所有模块公共配置
- 模块 `build.gradle` 通过 `ext` 辅助方法声明依赖：`addModuleDeps(...)`, `addJEI()`, `addMixinSquared()`,
  `addCurios()` 等
- `neoforge.mods.toml` 由 `templates/mods-base.toml` 与模块模板合并生成
- 新建模块：`./create_module.sh <ModName> <mod_id> "显示名" <group>`

## 5. 命名规范

| 类别            | 规范                 | 示例                                         |
|---------------|--------------------|--------------------------------------------|
| 接口            | `I` 前缀             | `IEgoItem`, `IPlayerRcf`, `IHasHoldAnim`   |
| Mixin 唯一字段/方法 | `$` 前缀（模块名+$）      | `resonator_combat_framework$proxy`         |
| 包名            | 全小写 snake_case     | `entity_animation`, `goldenboughs_lib`     |
| 常量/枚举值        | `UPPER_SNAKE_CASE` | `MAX_HEALTH`, `PHYSICS`                    |
| ID/常用值        | 静态变量引用，不硬编码        | `Rcf.ID` 而非 `"resonator_combat_framework"` |
| 静态方法调用        | 必须带类名              | `ClassName.method()`                       |

## 6. 编码约定

### Mixin

- 所有 `@Mixin` 类必须放在 `src/main/java/`，使用 Java 编写
- 业务代码（API/模型/网络/工具）放在 `src/main/kotlin/` 下使用 Kotlin
- `@Unique` 注解的字段/方法名必须以模块名 `$` 开头

### 事件处理

- `@EventBusSubscriber` 自动选择对应 bus，通常只需定义 `modid` 和 `value`
- 事件按事件的类分类（不是按作用），放在 `events/` 包下
  - 双端事件 → `architecture/<mod>/events/`
  - 客户端专属 → `architecture/<mod>/events/client/`
  - 事件 subscriber 只做转发，业务逻辑放工具类
- `event/`（单数）= 自定义事件类；`events/`（复数）= 事件监听器

### Kotlin 格式化

- **Tab** 缩进（不使用空格）
- Package → 空行 → imports → 空行 → declaration
- class/object 的左花括号后无空行，成员之间空一行
- 属性明确标注类型，`@JvmField`/`@JvmStatic`/`@SubscribeEvent` 在注解行紧挨声明
- 客户端专属方法用 `// 客户端` 注释标记，并 guard `if (!isClient) return`
- 包分组：项目包优先，外部库次之，Minecraft/Forge 最后

### 文档规范

- 文档文件夹: `docs/`，放在模块根目录
- 文档文件名：使用中文文件名（如 `文档.md`）
- 每个模块一个文档文件，描述模块定位、结构、关键系统、依赖

## 7. 模块详情

### 7.1 GoldenBoughsLib（金枝库）

核心底层库，为所有其他模块提供公共 API 和框架。

**包结构** (`architecture.goldenboughs_lib/`):

```
java/  →  mixin/ (client/, world/, geckolib/)
kotlin/ →
  api/           — capability(能力系统), virtue(四美德), payload(网络包基类)
                  world/entity/ai/behavior/(行为树: BTNode + 组合/装饰/条件/叶子 + 黑板)
                  world/item/(IEgoItem, IEgoWeaponItem, IGunWeapon 等)
  client/        — gui/hudlayers(HUD图层系统), model/, particle/, renderer/, renderlayer/
  common/        — attribute(属性), entity/projectile, item, mobeffect, payload
  core/          — Lib.kt(@Mod), LibClient, LibConstants, LibEventHooks
  events/        — 事件监听器
  event/         — 自定义事件
  init/          — 注册初始化
  mixed/         — Mixin 接口
  util/          — 30+ 工具类
```

**关键系统**：

| 系统           | 位置                              | 说明                                    |
|--------------|---------------------------------|---------------------------------------|
| LcLevel      | `api/LcLevel.kt`                | ZAYIN/TETH/HE/WAW/ALEPH 风险等级          |
| LcDamageType | `api/LcDamageType.kt`           | 四色伤害：PHYSICS/SPIRIT/EROSION/THE_SOUL  |
| 行为树          | `api/world/entity/ai/behavior/` | 组合/条件/装饰/叶子节点 + Blackboard            |
| 美德系统         | `api/virtue/`                   | Fortitude/Prudence/Temperance/Justice |
| HUD层         | `client/gui/hudlayers/`         | 生命/理智/护盾条 + 斩击特效 + 画面滤镜               |
| 理智系统         | `event/rationality/`            | RationalityEvent + 恢复机制               |
| 护盾系统         | `common/mobeffect/`             | 四种伤害吸收护盾                              |

### 7.2 ResonatorCombatFramework（共鸣战斗框架）

战斗框架 + 玩家动画系统。依赖 GoldenBoughsLib。

**包结构** (`architecture.resonator_combat_framework/`):

```
java/  →  mixin/(EntityMixin, PlayerMixin, gecko_lib/)
          module/entity_animation/mixin/(LivingEntityRendererMixin)
kotlin/ →
  api/           — 公开 API 接口
  core/          — Rcf.kt(@Mod), RcfClient, RcfConstants
  events/        — EntityEvents, GameEvents, client/GameEvents
  event/         — AddGeckoLibCachePathEvent
  mixed/         — IPlayerRcf, IEntityRcf
  module/entity_animation/ — 玩家动画子模块
  util/          — ModelUtil
```

**玩家动画系统**：

使用自研 BedrockAnimator 引擎，不替换原版渲染。

数据流：

```
命令/外部调用
  → IAnimationMapper.trigger(animId)
  → EntityAnimationMapper.trigger(config) → ControllerManager.get(controllerName) → defaultController
  → BaseAnimationController.trigger(config) → 状态机 + crossfade
  → LivingEntityRendererMixin.render() → PlayerAnimationMapper.tickAndRender()
  → 逐控制器: tickBackend → BedrockAnimator.computeAndWrite → proxyModel
  → applyProxyToModel() → ModelPart
```

| 类                            | 作用                                                         |
|------------------------------|------------------------------------------------------------|
| `IAnimationMapper`           | 公开 API: trigger/stop/pause/resume/addController            |
| `EntityAnimationMapper`      | 抽象实现：管理 ControllerManager、路由 trigger/stop 到控制器             |
| `PlayerAnimationMapper`      | 玩家实现：init 注册控制器，tickAndRender 逐控制器渲染                       |
| `BaseAnimationController`    | 控制器基类：状态机(IDLE→TRANSITIONING→PLAYING→FADING_OUT)、crossfade |
| `BedrockAnimationController` | 具体实现：加载 BedrockAnimation，MoLang 求值，时间推进                    |
| `BedrockAnimator`            | 骨骼插值计算：pos/rot/scale 的 LINEAR/CATMULLROM/STEP 插值           |
| `ControllerManager`          | 双集合管理：Map O(1) + List 顺序，getRenderable 处理骨骼冲突              |
| `AnimationPlayConfig`        | 播放配置：animType/speedMultiplier/durationTicks/fadeInOut      |

过渡系统：`ProxyBoneConfigData.transitionTicks: Int`（tick 制，默认 10=0.5秒，0=即时）

### 7.3 EGOCurios（EGO 饰品）

管理 EGO 饰品，使用 Curios API 15 槽位 + GeckoLib 3D 渲染。
依赖 GoldenBoughsLib + ResonatorCombatFramework。

15 个饰品槽位：ego_curios, ego_curios_headwear, ego_curios_head, ego_curios_hindbrain, ego_curios_eye, ego_curios_face,
ego_curios_cheek, ego_curios_mask, ego_curios_mouth, ego_curios_neck, ego_curios_brooch, ego_curios_hand,
ego_curios_glove, ego_curios_left_back, ego_curios_right_back

核心类：

- `EgoCurioItem` — 饰品基类，Builder 模式配置四美德属性
- `GeoCurioRenderer<T>` — GeckoLib 饰品渲染桥接
- `CurioRegistry` — 15 槽位验证器（左右背槽互斥）

### 7.4 EGOEquipment（EGO 装备）

~110 武器 + ~30 护甲套装。依赖 GoldenBoughsLib + ResonatorCombatFramework。

**武器分类**：

| 大类 | 子类                                                   | 说明                  |
|----|------------------------------------------------------|---------------------|
| 近战 | axe/fist/hammer/knife/mace/spear/swords + 27 special | MeleeEgoWeaponItem  |
| 远程 | cannon/crossbow/gun(pistol/rifle) + 7 special        | RemoteEgoWeaponItem |

武器基类层次：`EgoWeaponItem → MeleeEgoWeaponItem / RemoteEgoWeaponItem → 具体子类`

**护甲系统**：5 风险等级材料（zayin/teth/he/waw/aleph），三件套，四色伤害减免系数

### 7.5 Abnormalities（异想体）

异想体实体 + 考验实体。依赖 GoldenBoughsLib + ResonatorCombatFramework。

| 实体类型        | 位置                                                | 说明         |
|-------------|---------------------------------------------------|------------|
| 异想体         | `TrainingRabbits`                                 | TETH 级训练兔兔 |
| 考验·紫色       | `GrantUsLove` (HE), `FruitOfUnderstanding` (TETH) | 紫色正午/黎明    |
| 考验·琥珀/深红/绿色 | 预留接口                                              | 接口已定义      |

考验接口层次：`IOrdealsEntity → IOrdealsAmberEntity / IOrdealsCrimsonEntity / IOrdealsGreenEntity / IOrdealsVioletEntity`

### 7.6 ImaginaryCraft（伞模块）

jarJar 聚合所有子模块为单一产物，数据生成调度中心 + 中文本地化中心。

```
ImaginaryCraft.jar
├── GoldenBoughsLib (jarJar)
├── ResonatorCombatFramework (jarJar)
├── EGOCurios (jarJar)
├── EGOEquipment (jarJar)
└── Abnormalities (jarJar)
```

`accesstransformer.cfg` 在此维护，全局生效。
