# ImaginaryCraft 项目

NeoForge 1.21.1 模组项目，Kotlin（KotlinForForge）+ Java（仅 Mixin）。
多模块 Gradle 架构，最终通过 ImaginaryCraft 模块 jarJar 聚合。

## 技术栈

- Minecraft 1.21.1 / NeoForge 21.1.230
- Kotlin 2.2.20 (KotlinForForge 5.11.0)
- GeckoLib 4.8.4 / Curios API 9.5.1

## 模块

| 模块                       | Mod ID                     | 说明                   |
|--------------------------|----------------------------|----------------------|
| GoldenBoughsLib          | goldenboughs_lib           | 核心库：伤害/美德/理智/行为树/HUD |
| ResonatorCombatFramework | resonator_combat_framework | 战斗框架：实体动画/装备渲染       |
| EGOCurios                | ego_curios                 | ~50 E.G.O. 饰品，15 槽位  |
| EGOEquipment             | ego_equipment              | ~110 武器 + ~30 护甲     |
| Abnormalities            | abnormalities              | 异想体 + 考验实体           |
| ImaginaryCraft           | imaginarycraft             | 聚合模块（jarJar）         |

模块详情见各模块 `docs/文档.md`。
